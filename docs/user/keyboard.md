# Keyboard

Most shortcuts work anywhere on the page. Shortcuts with <kbd>Ctrl</kbd>/<kbd>⌘</kbd> also work while a field has focus; plain letters do not, so you can always type.

| Keys | Action |
| --- | --- |
| Any letter | Open the palette and type |
| <kbd>/</kbd> | Open the palette |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>F</kbd> | Open the palette instead of the browser's find dialog |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>K</kbd> | Open the palette |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>,</kbd> | Open Settings |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>?</kbd> | Open this help |
| <kbd>Space</kbd> | Pick up or drop a focused grip handle |
| Arrow keys | Move a picked-up tile or group |
| <kbd>Escape</kbd> | Cancel a move, or close a popup |
| <kbd>Enter</kbd> | Run the highlighted result, or submit a form |

On most keyboard layouts <kbd>?</kbd> is <kbd>Shift</kbd> + <kbd>/</kbd>, so the help shortcut is <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>/</kbd>.

## Search and experiments

The palette lists the tiles that match, the result of any enabled experiment that can act on the query, a web search for it, and the commands. With the calculator on, `18*3` offers to copy `54`; with Paste links on, pasting two or more addresses into the URL field of Add link opens the bulk dialog instead.

## Moving tiles and groups

Focus a grip handle with <kbd>Tab</kbd>, press <kbd>Space</kbd> to pick it up, move with the arrow keys and press <kbd>Space</kbd> again to drop it. <kbd>Escape</kbd> cancels the move.
